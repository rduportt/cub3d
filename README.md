# cub3D

> A small 3D game engine using raycasting, inspired by Wolfenstein 3D.

## What's inside

- Raycasting with the DDA algorithm
- Rendering with MiniLibX
- Wall textures by orientation, floor and ceiling colors
- Map parsing and validation from a .cub file
- Movement with W A S D, rotation with the arrow keys

## Usage

```bash
make
./cub3D maps/<map>.cub
```
